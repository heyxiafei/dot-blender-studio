# Blender 小型产品 / MG 动画工作流

## 参考与最小资产

读取可访问参考，记录 URL、标题、实际观看范围、时长与源 FPS 是否已核实。先完整看约定范围，再按镜头列：开始/结束、主体、构图、相机/物体运动、光影、转场、必需资产与观察不确定性。严格还原原片时读 [精确参考重建](precise-reference-reconstruction.md)，执行来源证据、逐帧切点和原生时序规则；无法获得逐帧源时只称观察拆镜，不伪造 EDL 或帧级对齐。

选一个可完成范围。原创 6 秒 Demo 不必套历史 22 镜头；复刻整条广告不能偷换成几个精彩镜头。先做约定小样，再按新的明确范围延展。真实结构产品、场景实例、颜色与品牌状态分开计数；镜头不需要的历史型号不是前置条件。

模型遵守 [模型规范](model-workflow.md)。冻结源并记录哈希，动画可用优化副本但保留详细编辑源。继承实际单位/轴向/原点、独立根控制器与品牌对象。镜头需要独立显隐时避免多个实例共享同一集合开关；相机、灯光不混进模型 GLB。

## 预览 → 修订 → 正式渲染

先渲几帧真实运动测成本与功能，再做全时长低清预览，包含所有约定镜头与结尾。匹配任务先比较起中末关键姿态的占屏、投影与方向，修正后再看连续动作。记录分辨率、FPS、帧数、渲染器、采样和耗时，不把估算当实测。输出 FPS 是选择，不能倒推参考 FPS。

逐镜检查裁切、主次、速度与运动方向、可读性、反射、穿模、跳帧与剪切连续性。完整观看可辅以顺序接触表；抽帧不称全部画面检查，接触表不称实时播放。几何投影重叠不必然是碰撞。

绑定问题、镜头与版本后修正，只重渲受影响段。未变段核来源哈希，组装后检查接缝。用户已接受的片段建立保护范围；确实需要改变时说明原因与影响，再按适用授权执行。既不能重做污染已接受结果，也不能为“保留”而忽略新接缝缺陷。

正式渲染前冻结模型、场景、镜头表与设置。明确 inclusive/exclusive 范围，时长用帧数/准确 FPS；源为可变帧率时以实际 PTS 为准，不套恒定帧率公式。不得静默重复图补缺帧。运动模糊开启时还要检验子帧的旋转/约束/速度，整数帧正确不能排除 Euler 分支跳变。

## 两类 QA 和诚实记录

技术：帧序列完整性、最终编码帧数/尺寸/FPS/时长、音轨是否符合约定、严格全片解码、文件哈希。可用 [检查脚本](../scripts/check_video.py)。它只查音轨存在性，不验证音频来源、剪裁区间或音乐版权；严格对比的音频需另核波形/时长/听感。

视觉：按顺序覆盖全片、核对全部镜头，重要细节看原分辨率。短精确片应有与制作者不同的审阅视角，记录实际审阅者/方法、覆盖范围、残余差异和未检查项。没有独立审阅条件就写未做，不把自查伪称独立验收。实时播放能检查节奏；只有顺序接触表时明确限制。

碰撞：需要时几何筛查并视觉复核。零机身 OBB 候选不证明摄像头/按钮等全部件无穿模，也不证明精准复刻。无声版不冒充音乐版。PASS 只适用于明确检查项，不覆盖未检内容或用户审美判断。

## 可复现交付

至少包含：可打开 BLEND、最终 MP4、镜头表、必要且可分发的源资产、相对路径/版本/依赖说明、实际 QA、SHA-256 清单。GLB 和逐帧 PNG 按任务约定；大序列可不打包但说明。只交视频不得称工程已交付。

检查 linked libraries、外链图片/字体/脚本与绝对路径。优先将必要动画烘焙到时间线，交付源能独立编辑，不依赖未知自启动 handler。交付副本在新进程打开并重渲代表帧，记录实际结果；像素一致与文件哈希一致要分开，单帧复现不是全片重渲。新宿主端到端安装未测则明确未测。

包含别人图像的屏幕贴图仍是第三方素材，不因已打包到 BLEND 就变成原创或许可齐全。分享包清理私密账号/云盘 ID、凭证、完整对话、私人路径与无权再分发的媒体；不得单靠关键词扫描保证无泄漏。只在授权环境本地制作；上传或发布需用户相应授权与权利检查，分别记录生成、上传、字节复核和公开发布状态。
